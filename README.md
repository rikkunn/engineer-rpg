# その件、持ち帰ります。 ― SEたちの異世界RPG

SEあるあるを、探索・証拠集め・ターン制バトルにしたスマホブラウザRPG。タイトルは現在の仮題です。

## 現在の公開対象（2026-10-03）

[ゲームを遊ぶ](https://engineer-rpg.lungtheater.chatgpt.site) — Sites v4、ゲームソース `dbbdea8`。公開成功を確認済み。

ユーザーの指示により、ここまでの動作確認済み版をSitesへ公開しました。製品完成・AAA品質の認定ではありません。GitHubはPrivateを維持し、ゲームはURLを知っている人が遊べる公開範囲です。

- 全3章、13マップ、通常14戦闘＋3ボス、任意依頼3件、3結末。
- 調査・引き継ぎ・切替の3場面、全18手順の選択イベント。
- 全画面の地形、オリジナルドット絵、敵ごとの姿と行動、BGM・効果音。
- 4人は調整役・中途参加・後輩・古参。同じ案件を兼務し、調査・回復・復旧の特技を共有。
- 会議ミュート、要約ツールの食い違い、録画忘れ、仕様書不在、難読設計書、試験データ不明、過剰テスト、自動化と手動確認、認識齟齬、アジャイルの誤用、後出し仕様、AIによる短納期圧力を会話と選択へ統合。
- 有給休暇は本人HP・MP全回復と炎上解除、当該ターン休み。各人1戦1回、最後の稼働者は交代待ち。
- トイレ長居・定時帰宅・自社研修・健康診断による予告付き1ターン休み。連発と全員不在を防止。
- 4ターン目以降は1ターン5Gの残業代、上限60G。勝利報酬へ加算し、内訳を表示。
- 自動/手動保存、書き出し/読み込み、戦闘直前への復帰、結末後の再挑戦。

## 起動と検証

Node.js 22以上。ゲーム実行に外部ライブラリは不要。

```sh
npm run dev
npm run check
npm test
npm run build
```

開発URL：`http://127.0.0.1:4173`。`dist/`はゲームだけを含む公開用ビルドです。

画面テストはPlaywrightとEdgeを使用。`PLAYWRIGHT_PATH`で既存の`playwright/index.mjs`を指定できます。

```sh
node scripts/browser-check.mjs
node scripts/mobile-battle-check.mjs
node scripts/campaign-check.mjs
node scripts/leave-check.mjs
node scripts/audio-check.mjs
```

画像・検証ログはGit対象外の`artifacts/`に生成します。
