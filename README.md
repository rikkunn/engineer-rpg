# 炎上クエスト ― 納期だけは決まっている ―

システムエンジニアの「あるある」をブラックユーモアで描く、オリジナルの王道コマンドRPG。
ファンタジー世界の不具合や仕様変更を、調査・議事録・実装・引き継ぎで攻略します。

## 想定するゲーム

- スマホブラウザ向け、縦画面・タッチ操作。
- 初回1〜2時間の一人用短編。
- 2Dマップ探索、4人パーティー、ターン制バトル。
- 「ログを見ろ」「議事録の盾」「一旦持ち帰ります」など、SEの仕事が特技になる。
- 理不尽には対抗手段を用意し、準備と工夫が報われる設計。

## 仕様と残課題

[ゲーム仕様書](GAME_SPEC.md)に現在の設計案と完成判定をまとめています。
ユーザー確定事項と提案中の詳細設計は、仕様書の冒頭で区別しています。

次に決める・検証する項目：

1. 技術構成とブラウザでの実行方法、公開先。
2. 第一章のマップ、会話、チュートリアル、敵行動。
3. 各特技の効果・習得順・MPコスト、敵味方の数値、装備表。
4. 片手でのタップ移動、戦闘コマンド、文字サイズの操作感。
5. セーブの実装と、タブ終了・バックグラウンド復帰時の動作。
6. ドット絵・BGM・効果音の制作または利用条件を確認した素材の選定。

実装前のため、起動コマンド・テストコマンドは未定です。開発環境の導入時に追記します。
