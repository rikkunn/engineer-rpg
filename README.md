# 炎上クエスト ― 納期だけは決まっている ―

システムエンジニアの「あるある」をブラックユーモアで描く、オリジナルの王道コマンドRPG。
ファンタジー世界の不具合や仕様変更を、調査・議事録・実装・引き継ぎで攻略します。

## 想定するゲーム

- スマホブラウザ向け、縦画面・タッチ操作。
- 初回1〜2時間の一人用短編。
- 2Dマップ探索、4人パーティー、ターン制バトル。
- 「ログを見ろ」「議事録の盾」「一旦持ち帰ります」など、SEの仕事が特技になる。
- 理不尽には対抗手段を用意し、準備と工夫が報われる設計。

## 実行・検証

Node.js 22以上で、追加インストールなしで動作します。

```sh
npm run dev
# http://127.0.0.1:4173
npm run check
npm test
```

`npm run check`（JavaScript構文確認）は通過。テスト整備・ブラウザ検証は進行中です。`npm test`の通過状況は下記の引き継ぎ文書で更新します。

## 品質目標とレビュー

ユーザー指定の重要目標：SEあるあるをふんだんに盛り込み、笑えて共感できるゲームとする。AAA品質を目標に、Webサイト・WebフォームのようなUI/UXにしない。
レビュー観点はUI、UX、RPGとしてのボリューム、Webサイト/フォーム感のなさ、RPGとしての面白さ、スマートフォン操作性の6項目。全レビュアーがOKと判断するまで改善を続ける。未検証を合格としない。

初回の3レビュアーは全員不合格判定。LP・selectフォーム・縦スクロール構成を撤去し、全画面ゲームUIへ改修済み。敵の固有挙動と逐次演出を追加。再レビュー中であり、まだ承認は得ていません。
